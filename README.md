# РИРЦ — Интеграция Home Assistant для РИРЦ Брянской области

[![hacs_badge](https://img.shields.io/badge/HACS-Custom-41BDF5.svg)](https://github.com/Anat0l/hass-rirc32)

Интеграция для [Home Assistant](https://www.home-assistant.io/), позволяющая взаимодействовать с личным кабинетом [ООО «РИРЦ» Брянской области](https://lk.rirc.ru/).

## Возможности

- Просмотр информации по лицевым счетам
- Текущие показания приборов учёта (ИПУ)
- Передача показаний счётчиков
- Баланс и задолженность по квитанциям
- Информация о последних платежах (дата и сумма)
- Тариф по каждому прибору учёта
- Номер квитанции с расшифровкой периода
- Дата и время последнего обновления данных
- Кнопка принудительного обновления данных
- Сервисы для автоматизаций (`rirc32.refresh`, `rirc32.send_readings`)
- Диагностика (выгрузка состояния интеграции)

## Поддерживаемые устройства и функции

Интеграция работает с личным кабинетом [lk.rirc.ru](https://lk.rirc.ru/) и поддерживает:

| Тип | Описание |
|-----|----------|
| **Лицевые счета** | Любые лицевые счета, привязанные к учётной записи на lk.rirc.ru |
| **Приборы учёта** | Счётчики холодной воды, горячей воды, газа, электричества |
| **Квитанции** | Сумма к оплате, задолженность, период |
| **Платежи** | История платежей (дата, сумма, оператор) |
| **Передача показаний** | Отправка показаний ИПУ через API |

## Установка

### HACS (рекомендуется)

1. Откройте HACS в Home Assistant
2. Нажмите **«Интеграции»** → **меню (три точки)** → **«Пользовательские репозитории»**
3. Добавьте URL репозитория и выберите категорию **«Интеграция»**
4. Найдите **«РИРЦ»** в списке и нажмите **«Установить»**
5. Перезапустите Home Assistant

### Ручная установка

1. Скопируйте папку `custom_components/rirc32/` в директорию `config/custom_components/` вашего Home Assistant
2. Перезапустите Home Assistant

## Настройка

1. Перейдите в **Настройки** → **Устройства и службы** → **Добавить интеграцию**
2. Найдите **«РИРЦ»**
3. Введите логин (email) и пароль от [lk.rirc.ru](https://lk.rirc.ru/)
4. Нажмите **«Отправить»**

### Параметры конфигурации

| Параметр | Описание |
|----------|----------|
| **Логин (email)** | Адрес электронной почты, используемый для входа в [lk.rirc.ru](https://lk.rirc.ru/) |
| **Пароль** | Пароль от учётной записи lk.rirc.ru |

### Изменение учётных данных

Если нужно сменить логин или пароль, нажмите **«Перенастроить»** на карточке интеграции в **Настройки** → **Устройства и службы** → **РИРЦ**.

## Сенсоры

Для каждого лицевого счёта создаются:

| Сенсор | Описание | Категория |
|--------|----------|-----------|
| **Лицевой счёт** | Номер ЛС, адрес, количество приборов учёта | Диагностика |
| **Показания ИПУ** | Текущие показания каждого прибора учёта (с типом: вода, газ, электричество) | — |
| **Тариф** | Текущий тариф прибора учёта (отключён по умолчанию) | Диагностика |
| **Баланс** | Сумма к оплате по последней квитанции | — |
| **Номер квитанции** | Номер последней квитанции с расшифровкой периода | — |
| **Последняя дата оплаты** | Дата последнего платежа с ненулевой суммой | — |
| **Последняя сумма оплаты** | Сумма последнего платежа с ненулевой суммой | — |
| **Последнее обновление данных** | Дата и время последнего успешного обновления | Диагностика |

| Кнопка | Описание |
|--------|----------|
| **Обновить данные** | Принудительное обновление всех данных |

## Сервисы

### `rirc32.refresh`
Принудительное обновление всех данных из личного кабинета.

### `rirc32.send_readings`
Передача показаний прибора учёта. Выберите лицевой счёт (устройство) и сенсор, откуда брать значение.

**Параметры:**

| Параметр | Тип | Описание |
|----------|-----|----------|
| `device_id` | устройство | Лицевой счёт РИРЦ (устройство интеграции) для передачи показаний |
| `value_entity_id` | сенсор | Сенсор, откуда брать значение для передачи (любой числовой сенсор) |

**Пример вызова в автоматизации:**

```yaml
service: rirc32.send_readings
data:
  device_id: <id вашего устройства РИРЦ>
  value_entity_id: sensor.rirc32_0000000_000000000_reading
```

Параметр `device_id` — это внутренний идентификатор устройства Home Assistant. В UI-автоматизациях он подставляется автоматически при выборе устройства из списка. Параметр `value_entity_id` может быть любым сенсором с числовым значением (например, показания умного счётчика).

## Примеры использования

### Ежемесячная передача показаний воды

```yaml
automation:
  - alias: "Передача показаний воды в РИРЦ"
    trigger:
      - platform: time
        at: "09:00:00"
    condition:
      - condition: template
        value_template: "{{ now().day == 20 }}"
    action:
      - service: rirc32.send_readings
        data:
          device_id: <id устройства>
          value_entity_id: sensor.rirc32_0000000_000000000_reading
```

### Уведомление о задолженности

```yaml
automation:
  - alias: "Уведомление о задолженности РИРЦ"
    trigger:
      - platform: numeric_state
        entity_id: sensor.litsevoi_schet_0000000_balance
        above: 0
    action:
      - service: notify.mobile_app_phone
        data:
          title: "Задолженность РИРЦ"
          message: >
            Баланс по лицевому счёту: {{ states('sensor.litsevoi_schet_0000000_balance') }} руб.
```

### Мониторинг платежей

```yaml
automation:
  - alias: "Уведомление о новом платеже РИРЦ"
    trigger:
      - platform: state
        entity_id: sensor.litsevoi_schet_0000000_last_payment_amount
    condition:
      - condition: template
        value_template: "{{ trigger.from_state.state != trigger.to_state.state }}"
    action:
      - service: notify.mobile_app_phone
        data:
          title: "Платёж РИРЦ"
          message: >
            Зафиксирован платёж на сумму {{ states('sensor.litsevoi_schet_0000000_last_payment_amount') }} руб.
            от {{ states('sensor.litsevoi_schet_0000000_last_payment_date') }}.
```

## Обновление данных

Данные обновляются **автоматически раз в 24 часа**, а также по запросу:
- Кнопка «Обновить данные»
- Сервис `rirc32.refresh`
- После успешной передачи показаний

Если обновление не удалось, сенсоры сохраняют последние известные значения и остаются доступными.

## Известные ограничения

- **Нет истории переданных показаний** — API lk.rirc.ru не предоставляет эндпоинт для получения истории переданных показаний или даты последней передачи.
- **Нет push-уведомлений** — данные обновляются только по расписанию (раз в сутки) или вручную. API не поддерживает real-time уведомления.
- **Один аккаунт — одна интеграция** — каждая учётная запись lk.rirc.ru добавляется как отдельная запись интеграции.
- **Показания передаются для всех ИПУ устройства** — при вызове `rirc32.send_readings` показания отправляются для всех приборов учёта, привязанных к выбранному лицевому счёту.

## Решение проблем

### Сенсоры показывают «Недоступен» (Unavailable)

- Убедитесь, что учётные данные (логин/пароль) верны.
- Проверьте доступность сайта [lk.rirc.ru](https://lk.rirc.ru/) в браузере.
- Нажмите кнопку «Обновить данные» или вызовите сервис `rirc32.refresh`.
- Проверьте логи Home Assistant на наличие ошибок `custom_components.rirc32`.

### Ошибка «Invalid login or password»

- Проверьте, что логин и пароль корректны — попробуйте войти на [lk.rirc.ru](https://lk.rirc.ru/) вручную.
- Если пароль изменился, используйте **«Перенастроить»** на карточке интеграции.

### Ошибка «Session expired»

Интеграция автоматически обновляет сессию. Если ошибка повторяется, перезагрузите интеграцию или выполните перенастройку.

### Включение отладочных логов

Добавьте в `configuration.yaml`:

```yaml
logger:
  default: warning
  logs:
    custom_components.rirc32: debug
```

## Удаление

1. Перейдите в **Настройки** → **Устройства и службы**
2. Найдите **РИРЦ** и нажмите на карточку интеграции
3. Нажмите **меню (три точки)** → **«Удалить»**
4. Подтвердите удаление

Все сенсоры, устройства и данные интеграции будут удалены. Если интеграция была установлена через HACS, её также можно удалить через HACS → Интеграции → РИРЦ → Удалить.
