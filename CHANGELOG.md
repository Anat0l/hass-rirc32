# Changelog

## [1.0.0] - 2026-02-09

### Добавлено / Added
- Первоначальный релиз / Initial release
- Авторизация и работа с личным кабинетом lk.rirc.ru
- Сенсоры: лицевой счёт, показания ИПУ, тарифы, баланс, номер квитанции, последняя дата оплаты, сумма последней оплаты, дата последнего обновления
- Кнопка принудительного обновления данных
- Сервис `rirc32.refresh` — ручное обновление данных
- Сервис `rirc32.send_readings` — передача показаний приборов учёта
- Автоматическое обновление данных раз в 24 часа
- Поддержка реавторизации и рекофигурации
- Диагностика интеграции
- Русская и английская локализация
